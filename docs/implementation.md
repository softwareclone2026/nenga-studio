# 実装メモ

## 座標系

- 用紙・カードの寸法はすべて mm で持ち、描画の直前に pt（1pt = 1/72inch）へ
  変換します（`mm.pt`）。`NengaCore` のモデルは mm、Core Graphics に渡す値は pt です。
- 面のレイアウトは「カード左上が原点・y は下向き」で定義し、描画時に
  `cardHeight - y` で Core Graphics の座標（左下原点・y 上向き）へ変換します。
- 印刷時は用紙の向きに応じて、カード座標を用紙座標へ回転・平行移動します
  （`PostcardExport.applyPaperTransform`）。PDF の MediaBox は実寸の pt です。

## 縦書きの組版（`TextEngine`）

Core Text の `kCTVerticalFormsAttributeName` を使うと字形ごと 90 度回ってしまう
ため、この実装では**1 文字ずつ em ボックスへ置く方式**で縦組みを自前で作っています。

- em ボックス（1 文字分）はフォントサイズと同じ正方形。字形は em ボックスの中央に
  置き、`ascent`/`descent` からベースラインを決めます。
- 句読点（、。）は右上へ 0.5em 寄せます。
- 長音（ー）、括弧（「」『』（）など）、波ダッシュは 90 度回します。
- 小書き仮名（っゃゅょ など）は右上へ寄せます。
- 算用数字と欧文は連なりをひとまとめにして 90 度回します（縦中横・横倒し）。
  電話番号や西暦が縦書きでも読める形になります。
- 列は右から左へ進み、`alignment` は列の上下の寄せ（上寄せ・中央・下寄せ）として
  働きます。折り返しは、回転させた欧文の実幅も含めて測ります。

## モチーフ（`MotifRenderer`）

イラストはすべてベクターで、単位正方形（0〜1）で定義した図形を、縦横比を保った
正方形へ写して描きます。線幅は mm 指定なので、大きく配置しても細くならないよう
`lineWidthMM` で調整します。

- 絵柄: 干支のイラスト（2027 未年・羊）、干支の漢字、松、竹、梅、松竹梅、富士山、
  南天、水引、扇、門松、雪輪
- 文様: 金雲（霞）、麻の葉、七宝、飾り罫
- 配色は 6 種類（紅白金・藍と金・抹茶と生成り・桃と金・墨と銀・ポップ）から選び、
  「メインの色」で主要な色だけ差し替えられます。

線を重ねて輪郭が汚くならないよう、雲は 1 つのパスにまとめてから塗り、羊の体は
輪郭を先に描いてから内側を塗ることで、もこもかの塊が 1 つの形に見えるようにして
います。

## 書類の形式

`.nenga` はフォルダ型のパッケージです。

```
書類.nenga/
  document.json    住所録・文面・レイアウト設定・差出人
  assets/          文面に貼った写真の実データ
```

`document.json` は `NengaDocument` の JSON で、`formatVersion` を持ちます。
将来形式を変えるときはこの番号で判別します。

## 画面の描画と印刷の一致

画面のプレビューも PDF も、同じ `PostcardRenderer` で描いています。プレビューは
`makeCGImage`（ビットマップ）を SwiftUI の `Image` に渡し、印刷は `makePDF` の
ベクター出力を PDFKit に渡します。プレビューだけに写真のプレースホルダや
ガイドを描くため、`RenderMode`（print / preview）で切り替えます。

## アイコン

アプリアイコンは `--make-icon` で、アプリ自身のモチーフ描画（金雲）を使って生成
しています。`scripts/make-app.sh` が PNG を作り、`sips` と `iconutil` で
`AppIcon.icns` に変換してバンドルへ入れます。
