# はがき印刷のメモ

## 郵便はがきの寸法

| 項目 | 値 |
| --- | --- |
| 用紙サイズ | 100 × 148 mm（官製はがき） |
| 私製はがき | 長辺 140〜154mm、短辺 90〜107mm の範囲が内国郵便の規格 |
| 郵便番号欄 | 7 桁。このアプリの既定は左 29mm・上 5mm から 5.7mm 幅 × 8.0mm 高 |
| 差出人欄 | 左下または右下。余白は既定 8mm |

郵便番号枠の位置は、はがきの個体差やプリンタのずれで数 mm 変わります。アプリの
「宛名印刷」画面で 0.5mm 単位に調整し、**位置合わせシート**で確認してください。

## 印刷の向き

はがきは短辺を幅にして縦送りで印刷する機種が一般的です。その場合、148×100mm の
デザインを 90 度回して 100×148mm の用紙に載せます。

| 設定 | 用紙 | 使いどころ |
| --- | --- | --- |
| 縦送り（時計回り 90 度） | 100 × 148mm | 既定。多くのプリンタはこちら |
| 縦送り（反時計回り 90 度） | 100 × 148mm | 上下が逆になったとき |
| 横送り（回転なし） | 148 × 100mm | 横送りできる機種・PDF 入稿 |
| 横送り（180 度回転） | 148 × 100mm | 横送りで上下が逆になったとき |

印刷結果が上下逆になったら、180 度違いの設定に切り替えてください。プリンタの
給紙方向によって正解が変わるため、最初に 1 枚だけ試し印刷するのが確実です。

## 位置ずれの補正

1. 「宛名印刷」画面で「位置合わせシートを印刷」を実行します。
2. 印刷したシートの上に、実際に使うはがきを重ねます（光に透かすと合わせやすい）。
3. 郵便番号枠の赤い枠と、シートの枠が重なるように「左からの位置」「上からの
   位置」を調整します。
4. 全体がずれている場合は「左右の補正」「上下の補正」で動かします。

補正値は書類ごとに保存されます。

## 官製はがきと無地のはがき

- **官製はがき・インクジェットはがき**: 郵便番号枠と「郵便はがき」の文字が
  印刷済みです。「数字だけ印刷（官製はがき）」を選び、枠の位置に数字を重ねます。
- **無地はがき・私製はがき**: 「枠も印刷する（無地はがき）」を選ぶと、赤い枠から
  印刷します。

年賀はがきのお年玉くじ番号が印刷されている下部の帯（約 12mm）には、宛名面が
かからないようにレイアウトしています。「ガイドを表示する」を有効にすると、
画面上でその範囲を確認できます。

## 文面の作り方の目安

- はがきの印刷可能領域は、プリンタの機種にもよりますが四方 5mm 程度内側です。
  文字や顔写真は外周 7mm より内側に置くと安全です。
- 文面は右から左へ流れる縦書きが基本です。賀詞（謹賀新年・迎春など）は右端に、
  添え書きは左寄せ小さめに置くと収まりが良くなります。
- 差出人を文面にも入れる場合は、左下に小さく入れると宛名面と重複しません。

## PDF 入稿やメール添付に使う場合

「PDF に書き出す」で作ったファイルは、ページサイズが 100×148mm または
148×100mm の実寸 PDF です。日本語フォントはサブセット埋め込みされるため、
フォントの無い環境でも文字化けしません。
